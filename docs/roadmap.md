# Roadmap

## Pós-MVP

- Seletor visual de região diretamente sobre preview capturado.
- Notificação nativa do sistema operacional.
- Modo fallback completo com `desktopCapturer` + `getDisplayMedia`.
- Heurísticas locais mais ricas de candle/frescor.
- Monitoramento de custo por sessão.
- Seletor de modelos OpenRouter free por disponibilidade/latência.
- Exportação CSV do journal.
- Perfis de risco por ativo.
- Replay de snapshots por sessão.

## Fora de escopo

- Auto-click.
- Auto-trade.
- Integração para executar ordens.
- Martingale automático.
- Promessas de assertividade.
